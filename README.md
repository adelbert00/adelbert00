### About me

I'm a full-stack developer at [Make It Flow](https://makeitflow.pl), based in Kraków. Since 2023 I've been shipping production software for promotional campaigns — lotteries, contests, cashback — end to end: Laravel backends, Vue / Inertia landings, mail/SMS integrations, and going live.

Most of that work sits in private client repos. Public GitHub is the tip of the iceberg.

- Currently building developer workflow playbooks (brief → backend / frontend) with Cursor
- Working on production promo platforms for agencies (FMCG, retail)
- Ask me about Laravel campaign systems, Vue 3 + Inertia, GSAP landings with zero reflow
- Reach me at **tazor1337@gmail.com**
